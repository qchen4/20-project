# ADR-001 MATLAB 浮点实验基线

- 状态：Accepted for experiment
- 日期：2026-10-22
- 授权依据：用户要求实现 MATLAB 模型，允许调整顶层约束以外的内部，并指定先使用合成数据。
- 设计选择者：Codex；适用范围：M0-morphology-v1 实验实现。
- 系统/临床/RTL 签核：未进行。
- 关联：O-01/O-06/O-08/O-09/O-11/O-13/O-15；ALG-004～009、NUM-002、REG-005/006。

采用逐帧因果 DC 跟踪及低通、上升过零完整周期、五维形态特征、启发式 SQI 和标准化线性回归。此组合容易观察状态和算术，也便于后续逐级定点化。

没有传感器空间布置、同步误差和真实标定数据，因此本实验不建立传播时间/PWV 模型。多通道用于独立质量门控，压力回归仅使用主通道特征。

未读结果与计算状态分离，连续计算可以继续，后续结果丢弃并记录独立溢出标志。该选择解决 M0 内部生命周期，不改变尚待冻结的硬件 CSR/IRQ 竞态语义。

正常配置未装载系数；演示系数人为构造并带 demo_only，显式开启演示才可通过模型就绪门控。真实系数接口提供岭回归拟合，但训练残差不能替代独立评价。

所有公式、参数和例外记录在 [M0 细则](../spec/algorithm-m0.md)。系统级 O-01 等问题仍保留，实验运行成功不构成完整算法签核。
