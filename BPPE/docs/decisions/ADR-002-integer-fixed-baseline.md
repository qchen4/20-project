# ADR-002 显式整数定点仿真与默认位宽

- 状态：Accepted for experiment。
- 日期：2026-10-22。
- 授权：用户要求定点化并评估效果，沿用既有内部设计调整授权。
- 选择者：Codex；范围：MATLAB 定点研究实现，不修改系统接口。
- 相关：NUM-001～009、O-08/O-14/O-15。

当前 MATLAB 安装未找到 fi，选择在基础 MATLAB 中以精确可表示的整数码模拟定点算术，加入逐级位宽、舍入、饱和、除零和整数精度保护。此方案可直接运行并导出测试向量，代价是需要后续 C++/RTL 独立逐位对照，不能以 MATLAB 运行通过代替硬件验证。

对 compact、balanced、wide 三组配置在同一合成测试集上比较后，选择 balanced 为实验默认。compact 出现低质量数据被接受的行为差异；wide 压力新增误差更低，但当前输出编码精度及未有综合数据不足以证明其资源代价值得采用。

保留 ADC 全范围阶跃导致的标准化特征饱和并报告数值错误，不隐藏或排除该场景。数据门控与算术优化可另作架构决策。

详细语义见 [数值规格](../spec/numeric-m1-matlab.md)，实测结果见 [EXP-002](../experiments/EXP-002-fixed-point.md)。
