# ADR-003 先完成 FPGA 工程原型

- 状态：Accepted for experiment。
- 日期：2026-11-05。
- 依据：负责人确认先做基于合成 PPG 的 FPGA 工程原型，真实产品模块替代和真实血压准确性单独验收。
- 目标板卡：负责人随后确认 ALINX AX7A200，RTL 仿真使用 QuestaSim；其他工具信息按负责人要求留待后补。完整器件型号和板级约束仍需在上板前核对。

本阶段验证事务行为、浮定点差异、可复现性和后续硬件资源开销，不把演示回归系数或合成数据结果当成真实血压有效性证据。该选择不批准现有系统草案中的所有接口、性能及数值参数。

先固化已知失效案例和验证入口，再进行整数参考与 RTL 的逐位对照。板级时钟、复位、引脚和主机连接不得凭 FPGA 系列名称推断。

阶段交付和未决项见 [原型推进计划](../prototype-plan.md)。
