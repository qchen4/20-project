# BPPE 算法规格

版本：0.2-draft.1；状态：Draft；批准：未批准。来源：原文 §5～7、§14。本文件规定算法需要明确的行为，不指定未经数据验证的血压公式。

实现进展：已建立 [M0-morphology-v1 实验基线](algorithm-m0.md)，采用因果滤波、心搏形态特征与线性回归接口，并完成合成测试。真实系数、标定与系统算法签核仍未完成。

## 算法选择与数据协议

- **ALG-001｜候选要求**：每个算法 profile 明确输入通道、物理位置/光路含义、采样率、时间要求、特征、模型、标定方式和适用条件。单路形态、多路时差、回归或小型非线性模型仍为候选，见 O-01/O-04。
- **ALG-002｜候选要求**：规范化帧包含 frame_seq、channel_valid、channel_saturated、gain_transition、gain_profile_id、optical_profile_id，以及各路 ppg 和 timestamp。通道模式来自配置快照。不得从主机写入时刻推断物理采样时刻。
- **ALG-003｜新增提案**：数据集清单记录数据版本、来源类别、通道含义、单位、tick、参考血压的测量方式及配对窗口、受试者/会话划分和标定信息。训练、调参和测试隔离，并检查受试者泄漏；个人标定数据与后续评价窗口的使用规则须明确。

合成数据、对抗数据和真实采集数据分开标记。合成数据用于验证数值和控制行为，不能单独支撑血压准确性。数据协议与存储格式待 O-13；当前没有真实数据集或已训练模型。

## 流水阶段合同

以下阶段功能来自原文，具体公式和参数均待批准：

1. 输入校验：有效掩码、序号、采集时间、饱和和增益变化；输出帧可用性及原因。
2. 预处理：基线去除、限带、归一化；输出滤波波形与每通道状态。
3. SQI：幅度、饱和、连续性和形态等质量量；输出 0～255 相对评分及拒绝原因。
4. 心搏与特征：合格心搏及算法定义的特征；输出观测窗口标识和使用的采样范围。
5. 估算：已批准模型及标定参数将特征映射为 SBP/DBP。
6. 校验与发布：检查范围、数值、质量、标定与可选时间连续性，形成结果快照。

- **ALG-004｜新增提案**：每阶段必须提供数学定义、参数单位、输入输出、保留状态、初值、更新条件和输出条件。用于 RTL 对照的浮点模型必须因果运行；使用未来样本的处理必须转换为明确的缓冲和输出延迟。
- **ALG-005｜候选要求**：时间戳使用模计数差值，但仅在批准的无歧义范围内有效；序号重复/倒退、采样缺口、通道偏差、增益切换均有确定的拒绝、恢复或重新预热规则。阈值与恢复方式待 O-03/O-06。
- **ALG-006｜候选要求**：区分“尚未积累足够观测”和“已经形成但未通过校验的测量”。二者是否发布无效快照及其超时政策待 O-06/O-09，不能由各模型自行选择。
- **ALG-007｜候选要求**：model/calibration 未配置或失效时不得产生有效结果。结果绑定计算所用的配置版本；参数更新边界见 O-08。
- **ALG-008｜候选要求**：复位、ABORT、ENABLE 清除、观测结束和断流时，每项状态必须有保留/清空/重建规则。正常数据恢复后需要的预热窗口待 O-06/O-11。
- **ALG-009｜候选要求**：浮点 M0 保存逐阶段中间结果，并绑定源代码版本、输入、参数和预期状态，支持复现与定位。

## MATLAB 模型接口提案

建议 m_model 中使用显式状态接口：`[out, next_state, trace] = bppe_step_float(frame, state, cfg)`，另设初始化函数。函数名和目录仍属实现建议，不表示已有文件。

out 至少区分是否产生新事件、是否有效、压力值、SQI、原因、结果序号、观测窗口和配置版本。trace 保存滤波波形、心搏位置、特征及拒绝原因。定点版本使用相同事务边界，避免通过调整输入对齐方式隐藏差异。

## 浮点算法评价

- **ALG-010｜新增提案**：对 SBP/DBP 分别报告相对参考血压的偏差、MAE、RMSE、最大/高分位绝对误差，以及有效结果率、失败原因分布和各数据划分的样本数。先冻结配对、剔除和标定规则，再评价独立测试数据。

使用场景、数据规模、准确性阈值、可接受无效率和参考测量协议均待 O-04/O-13。当前不设置数值验收门槛，也不宣称临床有效性。

## 算法冻结交付物

profile 说明、公式与参数、状态生命周期、数据协议与版本清单、M0 源码、固定测试向量、中间轨迹及已运行实验。算法冻结后进入数值定型；探索中仍可先建立预处理或接口实验，但应标记实验假设。
