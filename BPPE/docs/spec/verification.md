# BPPE 验证规格

版本：0.2-draft.1；状态：Draft；批准：未批准。来源：原文 §7～13。以下是系统验证计划；已执行的 M0 合成子集见 [EXP-001](../experiments/EXP-001-m0-synthetic.md)，定点对照见 [EXP-002](../experiments/EXP-002-fixed-point.md)，不代表系统验证全部通过。

## 验证层级

- **VER-001｜候选要求**：M0 浮点模型验证算法及数值敏感性，M1 C++ 整数模型定义定点事务行为，M2 RTL 验证硬件实现。MATLAB 定点模型作为 M0 到 M1 的中间验证层。
- **VER-002｜候选要求**：记分板只消费成功接受的输入事务，并绑定配置、复位和中止事件。拒绝的 PUSH 不得进入参考模型；完成周期由独立时序检查验证。
- **VER-003｜新增提案**：每次结果记录 pass、fail、not-run 或 blocked，附实际命令、版本、数据清单、日志和失败向量。静态检查、合成数据试验和真实数据评价分别报告。

## 验证组与需求追踪

下列 ID 是验证计划，不是已存在的测试名称。逐项实现后需在记录中链接脚本与结果。

- **V-SCOPE** → SYS-001/002/003、ALG-001/002：评审模块边界、通道 profile、输入转换和集成责任；无已批准 profile 时标 blocked。
- **V-BUS** → REG-001/002/003/009、ARCH-001：定向与随机读写、背靠背地址/数据相位、等待、IDLE/BUSY、支持的 burst、锁定访问、错误大小/地址/权限。断言副作用一次发生、错误响应符合协议、无意外状态改变。
- **V-CSR** → REG-003/008、SYS-006：逐寄存器检查复位值、保留位、W1C、自清、访问属性和非法配置。未知位域须先冻结。
- **V-FRAME** → SYS-004、REG-004/009、ARCH-002/003：单/多通道、暂存更新、完整/不完整帧、FIFO 满/空、突发、PUSH/pop 并发。检查接受顺序、无部分入队和无副本被修改。
- **V-TIME** → ALG-002/005、SYS-003/008：序号重复/倒退/回绕，采集时间回绕、缺口、跨通道偏差及增益切换；按批准阈值检查恢复。
- **V-ALGORITHM** → ALG-001/003/004/006/007/009/010、SYS-005：独立数据评价、因果性、观测窗口、标定、低质量与无效结果；核查配对与剔除协议。
- **V-NUMERIC** → NUM-001/002/003/004/005/006/007/008/009、SYS-008：最大/最小值、正负中点舍入、累加增长、溢出、除零、系数极值、长序列与零输入；逐阶段和端到端精度评价。
- **V-BITTRUE** → NUM-010、VER-001/002：MATLAB 定点与 C++ 对齐后，C++ 与 RTL 比较输出整数、有效位、原因、序号、epoch 和时间戳；按已接受事务匹配。
- **V-RESULT** → SYS-004/005/007、REG-005/006/007、ARCH-006/007：快照读取、未读溢出、ACK/publish 同周期、W1C/new-fault 同周期、中断屏蔽与解除。测试不得预设尚未冻结的优先级。
- **V-CONTROL** → SYS-006/008、ALG-008、REG-008、ARCH-002/004/005/007：各处理阶段复位、禁用、中止、重复 START、配置更新；验证恢复、FIFO 与快照生命周期。
- **V-PERF** → SYS-009/011、ARCH-008：在批准峰值输入和最坏工作负载下测量吞吐、FIFO、最大 stall、T_comp、T_irq；观测时间单独报告。
- **V-POWER** → SYS-010/011、ARCH-009：门控、空闲、唤醒、总线访问、快照保持；报告工艺、电压、频率、负载和每个合格结果能耗。
- **V-INTEGRATION** → SYS-001/002/006/007/011：SoC 地址、复位释放、IRQ、驱动、AFE adapter 与数据协议联调；综合、锁存器、CDC/RDC、STA 和目标工艺 PPA 检查。
- **V-REPRO** → ALG-009、VER-003/004：依据记录重新执行，检查配置/数据版本、日志和测试状态一致。

## UVM 与定向环境

原文建议层次：AHB-Lite master agent、reset/power agent、reference model adapter、scoreboard、protocol checker、coverage。参考模型可通过 DPI 或预生成向量接入，具体选择待工具环境确定。

先建立 reset → configure → enable/start → push → result → read → ACK 的定向 smoke，再扩展异常与随机测试。不能在没有估算模型时把测试发生器通过当成算法通过。

功能覆盖至少包含模式、有效掩码、质量类别、时间异常、复位/中止位置与输出状态。交叉覆盖须排除已批准的非法组合并说明理由；数值目标、SVA 清单和关闭标准待 O-15。

## 发布门槛

- **VER-004｜候选要求**：算法、数值、RTL、性能、功耗和系统集成分别签核。每项明确批准版本、验收标准、实际证据和遗留问题；存在未批准关键 TBD 时不能宣布完整签核。

M0 浮点准确性、M1 定点误差、RTL 逐位一致性互不替代。当前有 MATLAB 浮点/整数定点合成回归及新增误差证据，但正式误差预算、真实血压准确性、C++/RTL 和系统发布门槛仍未满足。
