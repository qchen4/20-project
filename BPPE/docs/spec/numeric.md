# BPPE 数值规格

版本：0.2-draft.1；状态：Draft；批准：未批准。来源：原文 §5、§7。所有内部位宽均未冻结。

实现进展：已有 [MATLAB 整数定点实验规格](numeric-m1-matlab.md) 及 [三组位宽评估](../experiments/EXP-002-fixed-point.md)。balanced 为实验默认，正式系统数值格式和 O-14 预算仍未签核。

## 表示法

- **NUM-001｜提案**：统一用 (S,W,F) 表示二进制定点：S=1 为二补码有符号，S=0 为无符号，W 为总位宽，F 为小数位数，实值 x=q×2^-F。禁止仅用含义不明确的 Qm.n 作为实现依据。

有符号范围为 [-2^(W-F-1), 2^(W-F-1)-2^-F]；无符号范围为 [0, 2^(W-F)-2^-F]。采样输入提案为 (0,24,0)，时间戳是模计数整数，不能按压力或滤波值的算术规则处理。

- **NUM-002｜原文提案**：SBP/DBP 使用 (0,16,7)，单位 mmHg，范围 0～511.9921875，步长 0.0078125。编码范围不是测量有效范围。最近舍入且无饱和时，单次最终编码误差至多 0.00390625 mmHg；这不是全链路误差上限。

## 必须补全的数值记录

- **NUM-003｜候选要求**：每个系数、状态、乘积、累加器和输出记录名称、物理单位、设计范围、观测范围、(S,W,F)、舍入、溢出、量化位置和依据。仿真最大值不得单独当作安全上界。

原文范围建议只作为探索起点：DC 状态 32～40 位，滤波波形有符号 24～32 位，SQI 特征 16～32 位，系数有符号 16/24/32 位，MAC 40～64 位。这些不是默认实现参数。

- **NUM-004｜候选要求**：明确乘法扩展、累加宽度、加法对齐、运算顺序和每个转换点。不能仅对最终输出量化。不同加法顺序或中间截位可能产生不同结果，M1 和 RTL 必须一致。
- **NUM-005｜候选要求**：舍入明确到负数和恰好半 LSB 时的规则；溢出明确到每一级的饱和/回绕及标志。除法或倒数、查表索引、除零返回值与结果失效行为均必须显式定义。不能依赖工具默认设置。
- **NUM-006｜候选要求**：系数编码、量化版本、加载完整性、激活边界和配置 epoch 归属必须确定。系数文件和模型配置需可追溯，见 O-08。
- **NUM-007｜新增提案**：反馈状态需检查量化后稳定性、长时间漂移、零输入残留振荡及复位恢复；范围和误差实验包含边界与长序列。

## 定点化流程

固定 M0 版本与输入数据，先分析范围，再从较宽格式开始，逐级量化系数、状态、特征和估算；最后执行全定点组合回归。逐级实验用于误差归因，不能替代组合回归。

MATLAB 定点模型可以使用 fi/fimath，但必须显式配置算术语义；缺少工具箱时可用整数仿真，仍须覆盖宽度、转换与溢出。C++ M1 使用明确整数规则，避免有符号溢出和工具默认转换造成差异。

## 精度评估合同

- **NUM-008｜新增提案**：分别评价 e_algorithm=BP_float−BP_reference、e_quant=BP_fixed−BP_float，以及 BP_fixed−BP_reference。SBP/DBP 分开统计；算法重训与位宽变动分开归因。
- **NUM-009｜新增提案**：数值比较按相同观测窗口/事务匹配，只在双方有效的匹配结果上计算压力误差；同时报告双方有效率、有效性不一致率、未匹配事件、心搏漏检/多检、位置偏差及原因标志变化。不得通过静默删除失败样本改善指标。
- **NUM-010｜候选要求**：M1 与 RTL 对相同已接受输入事务、配置和状态边界，输出位模式及标志逐位一致。完成周期另行验证；允许不同的字段必须事先列出，当前没有获批例外。

验收预算仍为 TBD：压力新增 MAE/RMSE/最大误差、行为不一致允许值、各级误差、允许饱和条件及恢复时间。见 O-14。算法参考误差和定点新增误差分别验收。

## 位宽扫描与交付

实验记录每组 (S,W,F)、舍入、饱和次数、压力误差、事件差异、数据样本数及失败向量。结果必须绑定配置和代码版本。位宽/存储量仅是成本线索，面积、时序与功耗以指定工艺和约束下的实现报告为准。

冻结交付物：完整数值记录、系数及编码、M1 源码、输入/预期输出整数向量、中间状态、范围与误差报告、版本标识。不得以“全部使用 32 位”替代各级数值定义。
