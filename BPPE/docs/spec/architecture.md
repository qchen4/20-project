# BPPE 微架构规格

版本：0.2-draft.1；状态：Draft；批准：未批准。来源：原文 §2、§6、§8～10、附录 A。模块名称为职责划分提案，不要求一一对应 RTL 文件。

## 功能模块与数据流

- 总线与 CSR：地址/数据相位配对、合法性、寄存器副作用、错误响应。
- 帧暂存与 FIFO：暂存字段、原子提交、容量和序号检查入口。
- 预处理：每通道滤波与基线状态。
- SQI：质量统计与拒绝原因。
- 心搏/特征：观测窗口、心搏状态和特征。
- 估算：模型参数、标定状态及算术调度。
- 结果校验与快照：原子结果、原因、epoch 和确认。
- 控制与中断：运行状态、复位/中止、事件保持与 irq。

逻辑流：AFE adapter → MMIO 暂存 → FRAME_PUSH → FIFO → 预处理 → SQI/特征 → 估算/校验 → 结果快照 → 主机 ACK。SQI 与特征是否并行、是否流水，需由算法和性能确定。

- **ARCH-001｜候选要求**：所有模块位于 HCLK 域；总线处理与 DSP 长计算解耦。不得在没有等待上限的情况下让软件访问等待整个观测窗口。
- **ARCH-002｜候选要求**：FIFO 元素是已接受帧的独立副本；暂存后续更新不得改变 FIFO 内容。配置是否在帧入队时附带快照或在测量开始时锁定，待 O-08/O-11；不可让同一观测窗口隐式混用配置。
- **ARCH-003｜候选要求**：内部传输定义接受事件、背压和数据保持。建议采用 valid/ready；如采用其他协议需文档化。同一元素仅在一次接受事件后推进，不能因停顿重复处理。

## 顶层处理状态机提案

原文给出六个主要状态：

- RESET：初始化；复位释放后进入 IDLE。RESET 是否是编码状态或复位条件由实现决定。
- IDLE：没有正在执行的测量；启动条件待定义。
- ACQUIRE：积累观测；满足窗口条件后进入 QUALIFY。
- QUALIFY：质量和心搏资格判断；通过后进入 ESTIMATE；不足和失败路径待定义。
- ESTIMATE：估算并校验；完成后请求结果发布。
- RESULT_PENDING：已发布结果等待确认；确认后的连续/单次模式去向待定义。

- **ARCH-004｜候选要求**：状态推进与软件可见行为确定。ABORT/FAULT 必须有处理路径，但原文未要求独立编码状态。状态机总数、具体编码和流水重叠均未冻结。

特别注意：若 RESULT_PENDING 阻止后续计算，就不会出现正常流中的第二个结果；若允许计算与待读取结果重叠，则需要独立控制状态或队列规则。O-11 必须选择一种一致方案，不得同时假设两种行为。

## 状态与并发事件

- **ARCH-005｜候选要求**：复位清空 FIFO、部分观测、数值状态和有效结果；ENABLE 清除的基线提案是受控中止部分观测。ABORT 完成边界、是否清 FIFO、已提交结果是否保留，待 O-11。
- **ARCH-006｜候选要求**：结果快照包含压力、质量、标志、时间戳、序号和配置 epoch。新结果不能部分更新快照，快照外事件状态须与快照内状态区分。
- **ARCH-007｜新增提案**：同周期事件的优先级必须在实现前冻结，包括 PUSH/pop、ACK/publish、W1C/new-fault、START/ABORT、软复位/完成、配置提交/帧接受。当前全部待 O-11，不隐含建议优先级。
- **ARCH-008｜候选要求**：FIFO 深度和共享 MAC 数量由峰值输入、主机突发、最坏服务延迟及计算预算推导。优先使用流式状态和紧凑特征窗口；需要整段波形存储时记录原因及容量依据。
- **ARCH-009｜候选要求**：门控不破坏总线、快照和必要状态；idle 的定义必须考虑 FIFO、在途算术和待处理控制事件。仅 RESULT_PENDING 是否允许算术 idle 由 O-07/O-11 确定。

## 逻辑数据类型

输入帧按原文附录 A：frame_seq 16、valid 3、saturated 3、gain_transition 1、gain_profile_id 8、optical_profile_id 8、ppg 3×24、timestamp 3×32，共 207 位逻辑载荷。物理存储可附带配置或内部标志，不能把 207 位直接视作最终 FIFO 宽度。

结果载荷：result_seq 16、SBP/DBP 各16、timestamp 32、SQI 8、reason_flags 16、config_epoch 8、result_valid 1，共 113 位；pending 与其他实时控制状态不在该载荷中。

## 接口冻结所需图示

v1 实现前补齐：AHB 读写/等待/错误、PUSH 接受与拒绝、结果发布/读取/ACK、复位和中止、连续突发与吞吐。当前没有系统级总线周期实现，不把概念状态顺序当作周期时序图。对应验证见 V-BUS、V-FRAME、V-RESULT、V-CONTROL、V-PERF。
