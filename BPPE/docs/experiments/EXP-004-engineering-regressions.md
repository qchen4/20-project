# EXP-004 固定失效案例与可复现验证入口

- 范围：合成 PPG 工程回归，不是产品或临床验收。
- 环境：Windows，MATLAB R2026b，基础 MATLAB；源码 SHA-256 使用 MATLAB 内置 Java 运行时计算。
- 来源：EXP-003 中的白噪声边界与强脉冲干扰；不调整算法、模型系数或质量阈值。

## 方法与判定

固定单通道、100 Hz、75 bpm、32 秒干净合成输入。运行白噪声 15 dB / seed=37，以及脉冲干扰 0 dB / seeds=11、23、37、51、79。

浮定点候选按“前一个候选边界帧、本候选边界帧”严格匹配；失效候选仍参与匹配和有效性比较。只有双方有效且压力有限的匹配结果参与新增误差统计。报告有效结果数和总数，不以少量保留结果的误差代替覆盖表现。

六个固定案例的工程回归条件：无未匹配区间、无有效性或接受帧差异、无数值故障；双方有效演示压力的最大差异小于 0.1 mmHg，且白噪声案例有有效结果。0.1 是这批固定案例的回归上限，不是批准的产品误差预算。

有效结果的周期折算心率与已知合成 75 bpm 相差超过 5 bpm 时，单独标记 `known-gap`。没有观察到这类偏差不等于质量算法通过一般验收；没有有效输出也不标为质量通过。统一入口会打印已知缺口，不能将工程退出码为零解释成全部质量问题已解决。

## 本轮观察

- 原有 41 项测试加 5 项新测试共 46 项通过；Code Analyzer 零发现。
- 白噪声案例的 9 个候选区间全部匹配，最大演示压力差约 0.061457 mmHg，重现 EXP-003 的边界。
- 五个脉冲案例共保留 10 个有效结果；seed=37 的三个有效结果中有一个周期折算心率误差超过 5 bpm，仍是已知质量缺口。
- 本轮没有通过修改质量阈值掩盖漏判，也没有声明真实血压效果。
