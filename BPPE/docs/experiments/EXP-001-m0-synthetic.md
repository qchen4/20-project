- 状态：Completed，实验范围内通过；不是算法或系统签核。
- 日期：2026-10-22。
- 执行环境：Windows，MATLAB 26.2.0.3386108 (R2026b)，基础 MATLAB。

## 实验问题与通过条件

验证逐帧模型能提取已知周期、在缺少系数时阻止有效压力、处理异常并保持未读快照。正常合成输入必须产生结果；75 bpm 对应周期误差小于 0.02 秒；最终 UQ9.7 编码误差不超过半 LSB。边界场景按各测试中的明确断言验收。

## 复现

在项目根目录的 MATLAB 中执行：

```matlab
addpath(fullfile(pwd,'m_model'));
run_bppe_tests;
demo_bppe;
```

本次通过 MATLAB -batch 真实执行，上述函数负责生成测试 CSV/MAT、演示 CSV/MAT/PNG。启动时受限环境出现文件系统错误，获得执行授权后使用本机 MATLAB 完成验证。

## 结果

25 项测试通过，0 失败，0 未完成，覆盖：

- 默认未配置模型、演示显式开关、正常周期与输出编码。
- 1～3 通道、列向量输入、次通道低质量门控。
- 16 位序号/32 位时间戳回绕、缺帧恢复、重复时间、通道偏差。
- 饱和、缺失有效位、增益变化、非法 ADC 数据。
- 平直波形超时、低幅度拒绝、因果前缀一致性。
- 未读结果保持与溢出、配置冻结、启动/中止/复位。
- 岭回归与无正则拟合、特征配置签名、特征包络。
- 非有限算术、压力次序检查、epoch/结果序号、有界状态存储。

24 秒演示共 2400 帧，产生 6 个工程门控通过的演示结果，全部 demo_only=true。周期特征约为 0.8 秒。压力由人为系数生成，因此本记录不报告真实血压误差或准确率。

首轮发现并修正 MATLAB 空结构数组追加的字段不匹配；修正后完成全部回归。图像已检查，导出显式使用浅色背景以避免桌面主题影响可读性。

本地证据：`m_model/artifacts/tests/test_results.csv`、`test_results.mat`、`matlab.log`；演示产物见 `m_model/artifacts/demo/`。生成产物被 Git 忽略，文档和源代码保留在工作区。
