## 参考与适用范围

[ADI Maxim Integrated PPG Algorithms Specifications](https://www.analog.com/en/resources/app-notes/maxim-integrated-ppg-algorithms-specifications.html) 同时讨论质量指标、误差与报告覆盖率，并列举运动、电子噪声、环境光和低灌注等影响因素。本文借鉴其评价思路，未复现厂商算法或测试集。

该参考文档的 WHRM 使用 PPG 与同步三轴加速度计，涉及心率和心搏间期。本实验只给已有 PPG 输入添加合成干扰，未新增硬件接口或加速度计通道，也未把其指标直接转换为血压验收标准。

## 数据与噪声定义

固定单通道、100 Hz、75 bpm、每次 32 秒。先生成无噪声 PPG，再按相同输入分别运行浮点与 balanced。噪声随机数流固定为 mt19937ar，种子为 11、23、37、51、79。

| 干扰 | 实现 |
| --- | --- |
| 白噪声 | 独立高斯样本 |
| 相关噪声 | 高斯输入经一阶滤波，极点 0.85 |
| 基线漂移 | 0.18 Hz 与 0.07 Hz 正弦叠加，随机相位 |
| 周期运动干扰 | 1.7 Hz 干扰，叠加 0.11 Hz 幅度调制和相关随机成分 |
| 脉冲干扰 | 1.5% 概率高斯脉冲，经 10 点指数衰减核扩展，叠加小幅白噪声 |

每类干扰先去均值，再按完整记录的干净 AC RMS 归一化。SNR = 20log10(干净 AC RMS / 添加噪声 RMS)，扫描 30、20、15、6、0 dB，共 125 次。输入重新量化到 24 位，超量程裁剪并标记饱和；本次扫描没有裁剪。

本实验的时域注入 SNR 与 ADI 基频及二、三次谐波功率定义的频域 pSNR 不相同。6 / 15 dB 只是测试点，不代表满足厂商条件。另导出一个明确实现的频域估计：Hann 窗、0.1 Hz 至 Nyquist，谐波带宽为 ±max(2fs/N, 0.08 Hz)。它使用已知合成基频，包含波形谐波截断和谱泄漏影响，不能视为厂商工具结果。

## 评价方法

1. **报告机会覆盖率**：以干净 balanced 输出的 9 个完整报告时刻为参考，将含噪有效报告按时间一对一匹配，容差为参考报告中位间隔的一半（本配置约 1.6 秒）。覆盖数 / 9。它衡量报告机会覆盖，不证明窗口内容相同，也不是 ADI 的 1 Hz 覆盖率。
2. **有效输出误差**：将有效结果的平均周期折算为 60 / period，与已知 75 bpm 比较，汇总全部有效报告的 MAE。另计绝对误差 >5 bpm 的报告数量。无有效报告时为 NaN，不填零。
3. **漏检 / 多检**：对照干净滤波模型的心搏完成事件，以 ±150 ms 一对一匹配。它是相对干净模型的稳定性指标，不是与 ECG 标注的临床心搏检测评价。
4. **演示压力扰动**：有效 SBP 相对干净输出 SBP 中位数的偏移，各次运行先算 MAE，再对有值的运行取平均。仅表征演示回归敏感性。
5. **定点新增差异**：只在前后候选报告边界帧都相同的浮定点窗口配对；不使用覆盖率的宽松容差。单独报告未配对数量、有效性不一致和双方有效压力差异。

覆盖率实现使用时刻匹配，避免极小的报告延迟把同一周期的相邻两条报告挤进一个硬分箱、导致覆盖率虚低。测试期间没有为提高覆盖率而调整算法阈值。

## 结果

下表每格为覆盖率 / 有效输出周期折算心率 MAE（bpm），汇总 5 个种子。每组有 45 个干净参考报告机会。破折号表示没有有效输出。

| 干扰 | 15 dB | 6 dB | 0 dB |
| --- | --- | --- | --- |
| 白噪声 | 100% / 0.219 | 4.44% / 1.013 | 0% / — |
| 相关噪声 | 100% / 0.313 | 2.22% / 0.522 | 0% / — |
| 基线漂移 | 100% / 0.214 | 100% / 0.626 | 86.67% / 1.579 |
| 周期运动干扰 | 100% / 0.597 | 0% / — | 0% / — |
| 脉冲干扰 | 66.67% / 0.214 | 37.78% / 0.469 | 22.22% / 8.105 |

30 dB 时全部干扰覆盖率 100%。20 dB 时脉冲干扰为 88.89%，其余为 100%。详细重复试验最小 / 最大覆盖率见 noise_summary.csv；5 个种子不足以估计可靠的总体置信区间。

0 dB 脉冲干扰有 10 个有效报告，其中 1 个周期折算心率误差超过 5 bpm，说明当前启发式质量门控会漏判。6 dB 白噪声只剩 2 个有效报告，相关噪声只剩 1 个，因此较小的条件 MAE 不能解释为该强度下性能良好。

### 新噪声集上的定点边界

浮点与 balanced 共 1105 个候选窗口严格匹配，未配对 0，有效性差异 0，其中 769 对双方有效。没有数值饱和、除零或精确整数范围故障。

双方有效结果的 SBP / DBP 合并最大绝对差异为 **0.0614568 mmHg**，出现在白噪声 15 dB、seed=37、第 6 个结果，具体是 SBP。该结果的浮点 / 定点平均周期约为 0.7985 / 0.8015 秒，说明还需检查心搏边界与特征选择的敏感性。复现快照见 white15_seed37.mat。

这大于 EXP-002 的最大差异，不能将原先 23 场景的 0.002643 mmHg 或最终 1 LSB 结论推广到所有噪声输入。本次只确认上述观察，未以修改算法来消除边界用例。
