# EXP-005 独立 C++ 标量整数参考

- 日期：2026-11-06。
- 范围：现有 MATLAB 整数算术合同的独立实现与对照；不增加产品误差门槛或修改 DSP 算法。
- 环境：MATLAB R2026b；WSL GCC 15.2.0、CMake 4.2.3、Ninja；C++17，严格警告，UndefinedBehaviorSanitizer。
- 代码入口：[c_model](../../c_model/README.md)、`bppe_export_integer_vectors`。

## 目的与方法

MATLAB 浮定点路径共用控制层，不能单靠相互比较证明所有数值行为。先把标量加法、乘法、除法、饱和、重缩放和整数平方根移到独立 C++ 实现，保留原有精确整数保护及故障规则，为后续完整 C++ M1 和 RTL 提供基础。

C++ 性质测试使用 128 位精确整数计算有理数距离和范围，检查负数、恰好半 LSB、零、精确整数界限、64 位容器边界、平方根舍入边界及故障累计。测试 oracle 的表示宽度独立于生产代码，且在 sanitizer 下运行。

MATLAB 再导出 19,783 个有限整数案例的原始结果和饱和/除零/精度计数。C++ checker 逐行核对全部字段；故意错误结果和错误故障标志作为负向控制，必须被拒绝。原始向量不包含产品或受试者数据。

## 本轮结果

- 238,452 项 C++ 性质检查通过。
- 19,783 个 MATLAB 向量全部一致，包含三类故障计数。
- CTest 四项测试通过：性质、错误结果拒绝、错误标志拒绝及 MATLAB 对照；sanitizer 未报告未定义行为。
- 加入向量导出器后，MATLAB 原有 46 项测试仍通过，Code Analyzer 零发现；固定强脉冲质量缺口仍单独报告，没有改变质量阈值。
- MATLAB 向量产物有参数和源码哈希；CMake 构建清单记录编译器、sanitizer 设置、C++ 源码和向量 SHA-256。

## 限制和下一步

这是标量数值层，不是完整 M1。尚未移植主机系数编码、因果滤波/心搏状态、质量与回归、输入控制或结果生命周期。数组广播与非有限浮点输入不在整数 API 范围；合法分数位参数范围为 0～52。

下一步可沿已存在的 MATLAB 截位位置建立预处理流式参考及逐帧原始码对照。板卡已确认 AX7A200，RTL 仿真工具已确认 QuestaSim，版本和路径按负责人要求留待后补；本实验不依赖板级引脚或总线选择。
